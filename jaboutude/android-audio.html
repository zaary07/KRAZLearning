Écouter écran verrouillé sur Android

JabouTube Audio — prototype Android

Le lecteur Web intégré YouTube ne peut pas continuer à jouer lorsque le téléphone est verrouillé. Pour contourner cette limite technique, JabouTube dispose d'un lecteur natif Android séparé avec un service multimédia Media3.

Pour le tester, installe une fois JabouTube Audio à partir du fichier APK généré sur GitHub Actions, puis reviens sur une vidéo JabouTube et utilise le bouton « Audio écran verrouillé (Android) ».

Voir le build et récupérer l'APK Android

Ouvre la dernière exécution réussie, puis télécharge l'artefact JabouTube-Audio-Android-debug contenant l'APK. Après installation, lance une vidéo sur JabouTube et appuie sur le bouton audio natif avant de verrouiller l'écran.

Cette fonction est expérimentale. Elle utilise un extracteur de flux indépendant de YouTube ; certaines vidéos protégées peuvent ne pas fonctionner et les changements de YouTube peuvent interrompre la lecture. Ce n'est pas une fonction garantie ni une lecture écran verrouillé à l'intérieur du navigateur. Le code source de l'application et ses dépendances doivent être vérifiés avant toute distribution publique.
